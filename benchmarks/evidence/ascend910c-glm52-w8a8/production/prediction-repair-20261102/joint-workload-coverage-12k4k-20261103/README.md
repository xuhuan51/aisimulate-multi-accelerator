读取当前240行层表：活跃DP为1至3且每活跃DP仅1个请求时，存在覆盖到约16K KV的点；活跃DP=4，或者每活跃DP有2至3个请求时，当前KV上界约10K，且不同层的精确上界略有差别。因此12K/4K不是全部不能预测，也不是全部已支持。以上失败条件仅针对本次固定1P1D配置；换PD比例或并发会改变实际DP人口，需要重新检查。

K能够对这三个12K/4K配置输出结果，但不构成新workload精度证明。在已有8K等历史数据中，K仍遗漏大量eager运行时耗时。L对C1成功也只证明已有层数据覆盖了该次原生调度访问的shape，不能将旧workload误差直接迁移过来。

要支持更全面的12K/4K搜索，应补齐活跃DP=4以及每DP多个请求在12K至16K以上KV区间的合格层调用数据，覆盖所有结构层类型；同时满足真实KV容量约束，并继续修复Prefill MoE和请求调度时序。TP32、其它并行方式和更长上下文须另外覆盖，不能直接复用TP16层数据。

`summary.json`包含六个任务的完整命令、不可变镜像ID、返回码、输出位置、预测指标与守恒结果；各任务的独立JSON和日志同目录保存。预测数字没有对应12K/4K实测值，不能用来计算或宣称预测误差。
